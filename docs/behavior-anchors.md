# 24项原创行为锚点（am-0.2）

每项的未知=null；无证据不等于0。每个0–4级都必须有用户行为、独立任务谱系、执行结果、反证检索与不确定性说明；结果只有agent宣称时不通过。人类明确作出的委派属于相关决策，但尚未执行的要求不等于稳定实践。所有锚点均为本项目原创综合。

## A1 明确用户要解决的问题和验收条件

- 0：在有相关机会的任务中，观察到用户未能明确用户要解决的问题和验收条件，有可归因失败和核验；不是agent单方错误。
- 1：用户部分明确用户要解决的问题和验收条件，仍需显著指导或存在重要遗漏；结果和遗漏可查。
- 2：用户在常规任务完整明确用户要解决的问题和验收条件，执行结果经后续独立核验；不从单次成功推断稳定。
- 3：用户在至少两个独立任务稳定明确用户要解决的问题和验收条件，能据反馈调整，分别有可核验结果；排除续接和重复示例。
- 4：用户在至少三个独立任务、不同或高要求场景可靠迁移明确用户要解决的问题和验收条件，解释取舍并核验结果。
- 反证与不确定性：检索同范围失败、遗漏及替代解释；未找到反证不等于没有。说明为何足以该级、为何尚不足下一级；若冲突未解决则未知。
