# 数据流与隐私

1. **范围计划**：选择结构/深度模式、准确根目录、实例与UTC日期。计划展示路径和限制；确认摘要绑定范围。计划含本地路径，应私密查看。
2. **只读收集**：独立收集器零网络，不执行历史指令或代码，不导入agent运行库。结构模式只解析允许文件；深度模式只解析所选Codex/Hermes记录。排除凭据/.env/浏览器资料/邮箱与无关文件，不改源数据。
3. **去敏与私密账本**：常见秘密行、密钥形态、链接、邮箱、用户路径、长标识符被替换。去敏尽力而为，无法可靠识别全部姓名、健康/财务/其他个人资料。先检查私密账本，必要时缩小范围、人工去敏或用本地模型。0600文件、0700新目录，默认不打印正文。
4. **语义评估**：CLI collect/evaluate不联网。Skill用当前agent模型分析去敏记录；云模型会把这些历史/摘要送入其提供商上下文。不能宣称云agent评价完全离线。真实离线需本地模型。
5. **本地报告**：证据、日期、任务ID、评分理由、人类贡献、agent活动、结果/反例、工作生活模式和建议只在私密报告保存。不要上传、提交git或公开托管。
6. **明确确认后发布**：skill通过publish-plan展示全部聚合字段、可选昵称、目标站点和摘要。只有用户确认准确字段与目标，publish才联网。上传评分版本、类型、六维分数、总分/区间、覆盖率、证据质量和选填昵称；昵称与分数也可能是个人信息。API拒绝额外字段，不接收原文、代码、文件、路径、证据、任务ID或头像URL。缺证据结果留本地，不进入完整评分排行。
7. **网络元数据**：应用不存IP、user-agent或历史路径，不启用应用观测日志。Cloudflare等网络服务可能处理请求IP和网络元数据，受供应商政策约束。
8. **私密删除能力**：CLI生成随机256位token，在任何网络请求前以0600写入指定私密receipt，通过Authorization传输；服务器只存SHA256 verifier，不存明文token。公开URL/响应/排行无token。联网失败保留同一receipt重试以幂等避免重复。删除CLI要求对应记录ID确认；错token不能删除。凭据遗失不能证明匿名归属。
9. **保留与头像**：服务器随机生成像素头像seed，不存图片。90天到期，查询立即排除；后续挑战请求清理过期记录，供应商备份可能保留至其期限。

文本预算：每文件最多读1MB、共8MB、200文件、500去敏记录、20秒。大JSONL读头尾各512KB并标截断；不完整JSON文档可能跳过。SQLite只读按日期SELECT最多500条、每条6000字符、查询10秒/进程15秒、源数据库最多2GB。8MB限制返回数据与文本读取，不保证SQLite底层页读取总量。坏行、超限、不支持schema和拒绝访问都须报告不完整，不能放宽权限。

拒绝symlink（包括父路径）及非普通文件。文本只读NOFOLLOW/NONBLOCK打开并复查inode，防FIFO和常见替换。主动攻击者可并发改写父目录时仍有竞态限制，不要在此类目录运行。SQLite WAL只读打开可能需要已有sidecar权限；失败不修复库、不扩大权限。

防滥用采用同源校验、4KB body上限、一次性120秒工作量证明、幂等、原子全局10条/分钟及2000条存储上限。它控制资源，不验证身份或真实性；攻击者仍可能占用匿名额度。排行是实验性自评，不能据此做招聘/认证判断。本地签名或删除token不防评分伪造。
