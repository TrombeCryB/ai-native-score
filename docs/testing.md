# Skill-only 验收

公开仓库只运行收集器/评估器/报告/聚合发布客户端测试，全部fixture为合成数据。网站与服务端的测试在独立私有项目维护。

覆盖：六轴等权与整数总分；缺证据null及可能区间；严格聚合字段/版本/范围；引用证据与多任务锚点；重复证据不加分；非程序员/短提示词不扣分；canary去敏；恶意历史不执行；日期选择；symlink/FIFO；大日志头尾预算与截断；80个未使用skill不给分；同任务续接合并；Hermes只读查询；发布前准确字段/目标摘要确认；凭据重试；返回URL无token；私下删除确认。

真实适配器另做最小本地只读兼容性检查：两个Hermes实例所需schema、数值时间戳与既有WAL/SHM均可读；各自最多两条角色样本可解析。Codex最多一个JSONL/256KB头尾窗口可解析元数据及人类/agent事件。只保存私密结构统计，没有公开真实原文、评分或账本。最小样本通过不证明长时段完整覆盖；实际评分仍需准确日期计划，预算超限需分批。

校验器不能证明模型语义判断正确或保证注入抵抗；云模型会接收去敏上下文，去敏不能识别全部个人资料。真实长时段语义评估尚未执行。

公共API尚未部署，没有默认上传端点；发布测试用隔离的合成transport，不构成公网端到端验证。
