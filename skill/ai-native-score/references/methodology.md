# AI Native Score 原创指标 am-0.1

这是基于公开框架启发的原创综合指标，不是通用已验证的 AI-native 等级，也没有机构认证或背书。教育素养框架不等于职业能力评估。全部指标措辞和实现为原创；外部材料仅作概念来源。

六轴等权，每轴四个指标：

| 维度 | 指标 |
| --- | --- |
| A 目标与委派 | A1 目标与验收标准；A2 按能力限制选择工具或不用AI；A3 分配人机责任；A4 约束、取舍和停止条件 |
| B 上下文表达 | B1 相关输入及来源；B2 受众、格式、约束与示例；B3 识别缺失、过期、矛盾；B4 根据反馈更新并区分事实、假设、指令和非可信材料 |
| C 工作流编排 | C1 合理阶段与依赖；C2 端到端集成产出；C3 检查点、失败恢复和升级处理；C4 复杂度、耗时、成本和维护权衡 |
| D 评估与判断 | D1 对实际验收标准检查；D2 独立验证、负例与边界案例；D3 识别无依据断言、错误、不确定性与偏差；D4 修正并复核最终结果 |
| E 学习与复用 | E1 重复需要变为复用资产；E2 跨任务适配；E3 用失败反馈改进；E4 维护版本、示例、评估与知识 |
| F 安全与责任 | F1 数据与秘密最小暴露；F2 合理权限、审批、可逆性和人类监督；F3 正确响应非可信内容和不安全行为；F4 责任归属、来源、适当披露和权利影响 |

统一行为锚点：

- **未知 null**：缺少相关观察，不能判断。
- **0**：在相关观察任务中未展示该能力。需要实际相关证据，缺数据不是0。
- **1**：展示基本部分，但需要大量指导或存在重要遗漏。
- **2**：在常规任务中完整展示。
- **3**：多个独立任务中稳定展示，并适应反馈或复杂情况。
- **4**：在不同或高要求场景可靠迁移，有结果佐证，并作合理取舍。

指标证据保存在本地：证据ID、日期、任务分组、人类贡献、agent活动、实际结果、反例及评分解释。同一任务的多个文件、重复记录或会话续接不算独立重复。模型评估仍可能误读，请检查原始范围与私密账本；本工具没有验证真实能力，也不能防止伪造评分。

完整维度 = 25 × 四指标均值。完整总分 = 六维均值，显示整数。不完整维度仅显示**已知部分的暂定轮廓**，不参与假精确总分；整体总分为未知。

缺证据下可能区间：下限 = 100 × 已知指标评级和 / 96；上限 = 100 × (已知和 + 4 × 缺项数) / 96。它表示尚未观察指标可能取值的数学范围，**不是统计置信区间**。显示区间下限向下取整、上限向上取整，避免排除可能值。六维75/75/75/50/75/50 → 完整总分67。

覆盖率 = 有评级指标数 / 24。置信度为证据质量低/中/高，**不是概率**。内部把低/中/高映射为0.3/0.6/0.9以形成整体描述，不用于能力加权。覆盖率不等于历史任务扫描比例；本地另报告截断和跳过情况。

结构扫描只发现技能元数据、工作流或包清单的存在，不给能力分。安装数量、tokens、提交数、多agent数量不加分。研究者的查证、复用与去敏和程序员一样可构成高质量证据；一个工具与短提示词只要结果可靠，也不扣分。复杂编排不自动证明验证或责任能力。
